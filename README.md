# 🚗 BookXe RWA Fleet Investment Vault - PoC

> **BookXe – Real World Asset (RWA) Backed Fleet Investment Vault**
> Đầu tư vào đội xe điện mà không cần mua chiếc xe. Nhà đầu tư chỉ cần gửi Stablecoin và nhận APY hàng năm.

## 📋 Tổng quan dự án

PoC (Proof of Concept) mô phỏng nền tảng đầu tư dựa trên tài sản thực là đội xe điện của công ty vận hành cho thuê xe. Nhà đầu tư không cần mua nguyên chiếc xe. Họ có thể gửi một khoản Stablecoin vào Vault và theo dõi khoản vốn, APY và lợi nhuận dự kiến.

APY được cập nhật dựa trên báo cáo tài chính do công ty vận hành cung cấp và được mô phỏng xác minh bởi bên thứ 3 thông qua Financial Oracle.

## 🚀 Hướng dẫn cài đặt & Chạy

### 1. Backend (Hardhat - Smart Contracts)

```bash

npm install

# Biên dịch contracts
npx hardhat compile

# Deploy contracts lên Hardhat Local
```

```bash

npm install
npm run dev  # http://localhost:5173
```

### 3. Chạy Tests


## 🎨 Dashboard UI

### A. Overview Cards
- **Total Value Locked (TVL)** — Tổng vốn huy động với progress bar

- **Annualized Return** — Lợi nhuận dự kiến/năm

### B. Investment Panel (Cột Trái)
- **Nạp tiền góp vốn** — Form nạp USDX

- **Mức cam kết APY** — 12%/năm
- **Auditor** — Tên kiểm toán viên

## 💡 APY Calculation (Simple Interest)

**Ví dụ:**
```
Principal: 10,000 USDC
APY: 12%
Period: 1 year
Simple Interest: 10,000 × 12% = 1,200 USDC
```

**Lãi đơn (Simple Interest) - không hồi tố:**
- Yield = Principal × APY × Time
- APY từ Oracle (verifiedApyBps = 1200 = 12.00%)
- Time: Elapsed seconds from `depositTimestamp`
- Formula: `Yield = principal * APY_bps * elapsed / (10000 * 365 days)`

## 🔒 Bảo mật & Phân quyền

### VehicleRWAVault
- **Owner:** Có toàn quyền quản lý Vault
  - `updateVaultName()`
  - `updateTargetCapUSDX()`
  - `fundRewards()`
  - `freeze()` / `unfreeze()`
- **Verifier:** Được phép cập nhật Oracle reports
- **Investors:** Chỉ Deposit/Withdraw/Claim/Redeem

### FleetFinancialOracle
- **Owner:** Có quyền update APY limits và cập nhật báo cáo
- **Verifier:** Có quyền cập nhật báo cáo tài chính
- **Investors:** Chỉ đọc báo cáo

### Emergency Pause
- Owner có thể freeze Vault để dừng tất cả giao dịch
- Gỡ freeze sau khi giải quyết xong
